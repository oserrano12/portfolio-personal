# Portafolio Personal Profesional

Portafolio web personal y profesional diseñado para exhibir trayectoria, proyectos de desarrollo de software, experimentos técnicos y habilidades de programación con altos estándares de calidad visual, accesibilidad y rendimiento.

---

## 🎯 Objetivo del Proyecto

Construir una plataforma web moderna, rápida, accesible y responsive que presente de manera equilibrada:
* **Perfil Profesional**: Trayectoria, experiencia, competencias técnicas y proyectos formales.
* **Proyectos Personales & The Lab**: Experimentos, herramientas, automatizaciones y proyectos de afición técnica.
* **Estándares de Calidad**: Implementación guiada por buenas prácticas de diseño de interfaz (UI/UX), accesibilidad web (WCAG 2.2) y optimización de rendimiento (Core Web Vitals).

---

## 🛠️ Estado del Proyecto

* **Fase Actual**: Preparación del entorno de trabajo, control de versiones y configuración de Agent Skills.
* **Control de Versiones**: Git & GitHub siguiendo *Conventional Commits* y estrategia de ramas estructurada.

## 📜 Flujo de Trabajo y Ramas

El desarrollo sigue una estrategia de ramas ordenada:
* `main`: Versión estable lista para despliegue / producción.
* `develop`: Rama base para la integración continua de cambios.
* `feature/*`: Desarrollo de nuevas características y secciones.
* `fix/*`: Correcciones y ajustes.
* `docs/*`: Documentación del proyecto.
* `chore/*`: Tareas de mantenimiento, dependencias y configuración.

Para más detalles, consulta la documentación en `docs/WORKFLOW.md` y `CONTRIBUTING.md`.
